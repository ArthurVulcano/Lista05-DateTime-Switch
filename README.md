# Lista 05 - DateTime e Switch em C#

Lista de exercícios focada em manipulação de datas e horas usando `DateTime` e estruturas de decisão `Switch` em C#.

## Exercícios

### Exercício 1: Data Atual
Exibe a data e hora atual em diferentes formatos.

### Exercício 2: Calcular Idade
Calcula a idade de uma pessoa com base em sua data de nascimento.

### Exercício 3: Dia da Semana
Identifica qual dia da semana é uma data fornecida usando `switch`.

### Exercício 4: Mês
Retorna o nome do mês de uma data fornecida usando `switch expression`.

## Como Executar

```bash
dotnet run
```
